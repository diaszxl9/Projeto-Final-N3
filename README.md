# Sistema de Gestão de Suporte Técnico (HelpDesk Estruturado)

Projeto desenvolvido como **trabalho final da disciplina de Estrutura de Dados I**.

O sistema simula o funcionamento de um serviço de suporte técnico (HelpDesk), permitindo o gerenciamento de clientes e chamados, utilizando diferentes estruturas de dados estudadas durante a disciplina.

 Sobre o projeto

O **Sistema de Gestão de Suporte Técnico** foi desenvolvido para simular o atendimento e gerenciamento de chamados técnicos.

O sistema permite controlar:

* Fila de atendimento de chamados;
* Histórico de clientes e chamados;
* Prioridade dos chamados;
* Cadastro e busca de clientes;
* Gerenciamento dos chamados técnicos;
* Organização dos dados utilizando diferentes estruturas de dados.

 Estruturas de Dados utilizadas

Durante o desenvolvimento foram utilizadas estruturas de dados fundamentais estudadas na disciplina:

* **Filas (Queue):** utilizadas para organizar os chamados de acordo com a ordem de atendimento.
* **Pilhas (Stack):** utilizadas para controle do histórico e operações que seguem o princípio LIFO.
* **Listas Encadeadas:** utilizadas para armazenar e organizar informações de clientes e chamados.
* **Tabela Hash:** utilizada para permitir uma busca rápida de clientes.

 Objetivo

O principal objetivo do projeto é aplicar, na prática, os conceitos de **Estrutura de Dados I** em um sistema que simula uma situação real de atendimento de suporte técnico.

O projeto busca demonstrar como diferentes estruturas podem ser utilizadas de acordo com a necessidade de cada operação, priorizando organização, eficiência e facilidade de acesso aos dados.

 Tecnologias

* **Java**
